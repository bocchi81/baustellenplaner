# BaustellenPlaner – Starter

## Was enthalten ist
- Responsive Wochenübersicht im Stil einer farbigen Baustelleneinteilung
- Beispielteam mit 17 Personen und Beispielbaustellen
- Einsätze erstellen, bearbeiten und löschen
- Wochenwechsel, Filter, Konflikthinweis, Druck/PDF
- Lokaler Browser-Speicher sowie JSON-Export/Import
- Demo-Schalter für Büro- und Mitarbeiteransicht

## Wichtige Einschränkung
Diese Version speichert Daten nur im Browser auf dem jeweiligen Gerät. Der Rollen-Schalter ist nur eine Vorschau und KEINE echte Anmeldung oder Zugriffssicherung. Nicht als gemeinsame produktive Mehrbenutzer-App verwenden und keine vertraulichen Personaldaten eintragen.

## Kostenloser nächster Schritt
Für echte gemeinsame Nutzung benötigt die App:
1. eine Hosting-Plattform für die Webseite (z. B. GitHub Pages),
2. eine zentrale Datenbank und Anmeldung (z. B. Supabase Free),
3. echte Rollen/Berechtigungen: Büro darf schreiben; Mitarbeiter dürfen nur ihre eigenen Einsätze lesen,
4. Tests für Datenschutz, Backups und gleichzeitige Bearbeitung.

Dafür müssen ein GitHub-Konto und ein Supabase-Projekt vom Betreiber angelegt werden. Kostenlose Tarife und Bedingungen können sich ändern; Verfügbarkeit/Limitierungen vor dem Einsatz prüfen.

## Lokal ausprobieren
Öffne `index.html` in einem aktuellen Browser. Für die Demo sind keine Installation und keine Anmeldung nötig.
